------------------------- things to keep in mind when create a new project -------------------


1. Where to start - Feature planning.

2. Design UI/UX:
    1. UX : First Principles/copy the biggest website out there.
    2. UI : Designer, today there are tools but haven't found any good one.

3. High level Design:
    1. Auth Provider.
    2. Database
    3. Backend stack.
    4. Frontend stack.
    5. Modules you'll have (common/ui/backend)
    6. Cloud to deploy to 

4. Low level Design (LLD):
    1. Schema
    2. Route Signatures
    3. Frontend Components - debatable.

5. ER Diagrams - 
    1.We can build these today, but usually not needed unless you're a very visual person.

6. How to think about feature:
    1. usually come from product
    2. If you're a founder, then just think whatever is right.

7. How much complexity is needed:
    1. Depends on the size of the company, For a startup, whatever helps you move fast who tech debt. For a 
    company there are lot of layers of reviews to go through.

-------------------- Bootstrapping:

---

1. npx create-turbo@latest

2. rename apps to, user-app and merchant-app. 

3. add tailwind to each app:
```
cd apps/user-app
npm install tailwindcss @tailwindcss/postcss postcss

follow more steps at tailwind documention with Nextjs.

same with cd ../merchant-app
```


---
instead of step 1st to 4th, you can simply follow this example "npx create-turbo@latest -e with-tailwind". 
or checkout their github.

----


4. add gloabal prisma db. 

packages/db:
```
npm init -y
npx tsc --init
npx primsa init
npx primsa migrate dev --name init
```

create packages/db/src/index.ts:
```
export * from "@prisma/client";
```

in packages/db/package.json:
```
  "exports":{
    "./client":"./src/index.ts"
  }
```

so everyone in app, will get client from here.by this:
```
import {PrismaClient} from "@repo/db/client"
```
