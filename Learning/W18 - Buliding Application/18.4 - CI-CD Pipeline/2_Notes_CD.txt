--------- 2. Create the CD pipeline --------------

main steps.
-- 1. Clones the repo
-- 2. Builds the docker image / Dockerize it.
-- 3. Pushes image to docker.
-- 4. Pushes it to EC2 or any other machine.


pre-requisites: 
1- create a repo at hub.docker.com 
2- create access token at hub.docker.come for github.
3- now at github repo/ setting/ security/ secrets and variables/ Actions/ secrets/ .. add docker username and 
    password. which will be used by github repo action.

Now, create .github/workflows/deploy.yml:
```
name: Build and Deploy to DockerHub

on:
  push:
    branches:
      - main

jobs:
  build-and-push:
    runs-on: ubuntu-latest
    steps:
      - name: Check out repo
        uses: actions/checkout@v2
      
      - name: Log into DockerHub
        uses: docker/login-action@v2
        with:
          username: ${{ secrets.DOCKER_USERNAME }}
          password: ${{ secrets.DOCKER_PASSWORD }}
      
      - name: Build and push to DockerHub
        uses: docker/build-push-action@v2
        with:
          context: .
          file: ./docker/Dockerfile.user
          push: true
          tags: potenz/paytm-100xdevs:latest  //your username and repo name at hub.docker.com

      - name: Verify Pushed Image
        run: docker pull potenz/paytm-100xdevs:latest
```


Now, out of these main steps.
-- 1. Clones the repo

4. -- Update workflow to pull latest image on the ec2 machine

deploy.yml
```
name: Build and Deploy to DockerHub

on:
  push:
    branches:
      - main

jobs:
  build-and-push:
    runs-on: ubuntu-latest
    steps:
      - name: Check out repo
        uses: actions/checkout@v2
      
      - name: Log into DockerHub
        uses: docker/login-action@v2
        with:
          username: ${{ secrets.DOCKER_USERNAME }}
          password: ${{ secrets.DOCKER_PASSWORD }}
      
      - name: Build and push to DockerHub
        uses: docker/build-push-action@v2
        with:
          context: .
          file: ./docker/Dockerfile.user
          push: true
          tags: potenz/paytm-100xdevs:latest

      - name: Verify Pushed Image
        run: docker pull potenz/paytm-100xdevs:latest
      
      - name: Deploy to EC2
        uses: appleboy/ssh-action@master
        with: 
          host: ${{secrets.SSH_HOST}}
          username: ${{secrets.SSH_USERNAME}}
          key: ${{secrets.SSH_KEY}}
          script: 
            sudo docker pull potenz/paytm-100xdevs:latest
            sudo docker stop paytm-100xdevs || true
            sudo docker rm paytm-100xdevs || true
            sudo docker run -d --name paytm-100xdevs -p 3005:3000 --restart unless-stopped potenz/paytm-100xdevs:latest
```

```


---------------------- Adding nginx - reverse proxy.  ---------------------------

5. Add nginx reverse proxy to forward requests from userapp.your_domain.com to the port on which the app is 
running.

by bash commands:
```
$ ssh -i key.pem ubuntu@ec2_ip

$ sudo apt install nginx

$ sudo vim /etc/nginx/sites-available/paytm-100xdevs


press i and paste the code:
`````
server {
    listen 80;
    server_name 54.88.60.76;  # Accepts all requests (or replace _ with your domain when you get one)

    location / {
        proxy_pass http://localhost:3005;  # Your Next.js app running in Docker
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
`````

Press Esc, then type :wq and hit Enter to save and exit.



$ sudo ln -s /etc/nginx/sites-available/paytm-100xdevs /etc/nginx/sites-enabled/

$ sudo nginx -t

$ sudo systemctl restart nginx
```
