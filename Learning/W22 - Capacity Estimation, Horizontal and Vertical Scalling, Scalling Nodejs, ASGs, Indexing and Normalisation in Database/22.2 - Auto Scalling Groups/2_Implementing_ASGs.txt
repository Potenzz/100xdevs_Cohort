--------- The Worked one: (But run the Application as root user, not recommended for security reasons.)
```
#!/bin/bash

# Load NVM environment
export NVM_DIR="/home/ubuntu/.nvm"
source $NVM_DIR/nvm.sh
source /home/ubuntu/.bashrc

nvm use 23

which node
which npm

# Install PM2 globally (if not installed)

# Now, set PM2_HOME after installing PM2

export PM2_HOME=/home/ubuntu/.pm2


# Navigate to app directory and start the app
cd /home/ubuntu/week-22
pm2 start index.js --name "my-app"

# Save the PM2 process list
pm2 save

# Set up PM2 to restart on boot **after saving the process**
pm2 startup systemd -u ubuntu --hp /home/ubuntu
sudo systemctl daemon-reload
sudo systemctl enable pm2-ubuntu
sudo systemctl restart pm2-ubuntu

# Log success
echo "Application started successfully with PM2"

# Redirect all output to a log file
exec > /home/ubuntu/userdata.log 2>&1
```

--------- Second one(Run Application with ubuntu user.)(The recommended one.): 
```
#!/bin/bash

# Load NVM environment
export NVM_DIR="/home/ubuntu/.nvm"
source $NVM_DIR/nvm.sh
source /home/ubuntu/.bashrc
source /home/ubuntu/.profile

nvm use 23  

# Set PATH properly
export PATH=$NVM_DIR/versions/node/v23.11.0/bin:$PATH

# Debugging: Verify node and npm are available
which node
which npm

# Ensure Node.js is globally available
sudo ln -sf $(which node) /usr/bin/node
sudo ln -sf $(which npm) /usr/bin/npm


# Install PM2 globally (if not installed)
npm install -g pm2


# Now, set PM2_HOME after installing PM2
export HOME=/home/ubuntu
export PM2_HOME=/home/ubuntu/.pm2

# Ensure PM2 directory permissions are correct
mkdir -p $PM2_HOME
chown -R ubuntu:ubuntu $PM2_HOME

PM2_PATH=$(which pm2)

# Run everything as ubuntu user
sudo -u ubuntu $PM2_PATH start /home/ubuntu/week-22/index.js --name "my-app"
sudo -u ubuntu $PM2_PATH save
sudo -u ubuntu $PM2_PATH startup systemd -u ubuntu --hp /home/ubuntu

# Set up PM2 to restart on boot **after saving the process**
sudo systemctl daemon-reload
sudo systemctl enable pm2-ubuntu
sudo systemctl restart pm2-ubuntu

# Log success
echo "Application started successfully with PM2"

# Redirect all output to a log file
exec > /home/ubuntu/userdata.log 2>&1
```

------------------ Now, to connect your domain name to load balancer -----------------

Load Balancers > listeners and rules > Add listeners 

-Select Protocol to HTTPS and its Port 443.

-Forward to created target group. 

--- Add SSL Certificate, either by certbot or create new with AWS by "Request new ACM Certificate"

- Request Certificate > Give your domain name > DNS validation > Create
- It will give CNAME name and CNAME value. 

Now, add these value to your dns provider.
- keep the type as CNAME
- the name will be CNAME name.
- the domain name will be CNAME value.

Then Certificate will be issued. 

- select Certificate and "Add"



------ Now, also create one more entry at your dns provider. 

- keep the type as CNAME. 
- the name will be your actual website domain name you want
- the domain value will be the DNS of load balancer we got earlier. 
i.e The DNS name : nodeapp-asg-1-1232172360.us-east-2.elb.amazonaws.com

------------------ Managing Metric by own ----------------------
If, there is some other metric you want ASGs to work accordingly then you can do it by this such code:

```
import { AutoScalingClient, CreateAutoScalingGroupCommand, PutScalingPolicyCommand } from "@aws-sdk/client-auto-scaling";

const client = new AutoScalingClient({ region: "us-east-1" }); // Change region as needed

const autoScalingGroupName = "my-auto-scaling-group";

// Step 1: Create Auto Scaling Group
async function createAutoScalingGroup() {
    const params = {
        AutoScalingGroupName: autoScalingGroupName,
        LaunchTemplate: { LaunchTemplateName: "my-launch-template" }, // Change as needed
        MinSize: 1,
        MaxSize: 5,
        DesiredCapacity: 2,
        VPCZoneIdentifier: "subnet-12345678,subnet-87654321", // Change to your subnets
        Tags: [{ Key: "Name", Value: "MyAutoScalingInstance", PropagateAtLaunch: true }]
    };

    try {
        const response = await client.send(new CreateAutoScalingGroupCommand(params));
        console.log("✅ Auto Scaling Group Created:", response);
    } catch (error) {
        console.error("❌ Error creating ASG:", error);
    }
}

// Step 2: Attach CPU-Based Scaling Policy
async function attachScalingPolicy() {
    const params = {
        AutoScalingGroupName: autoScalingGroupName,
        PolicyName: "cpu-scaling-policy",
        PolicyType: "TargetTrackingScaling",
        TargetTrackingConfiguration: {
            PredefinedMetricSpecification: {
                PredefinedMetricType: "ASGAverageCPUUtilization"
            },
            TargetValue: 50.0
        }
    };

    try {
        const response = await client.send(new PutScalingPolicyCommand(params));
        console.log("✅ Scaling Policy Attached:", response);
    } catch (error) {
        console.error("❌ Error attaching scaling policy:", error);
    }
}

// Execute the functions
(async () => {
    await createAutoScalingGroup();
    await attachScalingPolicy();
})();

```
